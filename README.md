# Valvontakamera

Android-sovellus (Galaxy A53), joka tekee puhelimesta liiketunnistavan valvontakameran.

- Liiketunnistus, jossa sadepisarat ja lumihiutaleet suodatetaan pois. Herkkyys säädettävissä.
- Full HD- tai HD-video ja esitallennus: tallenteeseen tulee 2 s ennen liikettä ja 2 s sen jälkeen.
- Telegram: yksi kuva tapahtumasta (kohta, jossa liikettä oli eniten) ja "Lataa video" -painike, josta 720p-video tulee ryhmään.
- Yön aikajana: liikekäyrä, jota kelataan sormella. Hyppy suurimpaan liikkeeseen ja seuraavaan tai edelliseen tapahtumaan.
- Puhelimen oman valon voi kytkeä päälle tai pois.

APK: **Releases → uusin → Valvontakamera.apk**
